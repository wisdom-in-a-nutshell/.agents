# References

Use this folder for durable implementation facts, command snippets, and operational lookup material for humans and agents.

Use `docs/architecture/` for system shape and `docs/projects/<project>/tasks.md` for active execution state.

## Retention Rule

Keep a reference doc only when it gives exact facts an agent needs to change or operate the repo safely: source-of-truth maps, command surfaces, field contracts, or known failure recovery. Move rationale to `docs/architecture/`, move active execution state to `docs/projects/`, and delete prose-only summaries that only restate code, tests, or another reference.
